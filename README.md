# 📄 CISSE Premium CV Builder

Un générateur de CV moderne, intuitif et hautement personnalisable, conçu pour aider les professionnels à créer des CV percutants en quelques minutes.

## ✨ Fonctionnalités Clés

- 🌍 **Format France / Côte d'Ivoire** : le formulaire et le CV s'adaptent aux usages du pays (âge, nationalité, photo, situation familiale, permis de conduire).
- 🎨 **Templates Professionnels** : Choisissez entre les styles _Executive_, _Creative_, _Minimal_ et _Classique_ (une colonne, noir et blanc, idéal pour la France).
- 🌈 **Thèmes de Couleurs** : 8 palettes de couleurs premium pour refléter votre identité visuelle.
- 🖼️ **Gestion de Photo** : Upload et aperçu immédiat de votre photo de profil.
- ✍️ **Édition Dynamique** : Ajoutez/Supprimez vos expériences, formations, compétences, langues et loisirs en un clic.
- 👁️ **Aperçu Temps Réel** : Visualisez les changements instantanément sur le rendu final.
- 📁 **Exportations Mobiles** :
  - **Télécharger PDF** : téléchargement direct (PDF image, html2pdf.js).
  - **Imprimer le PDF** : via la fenêtre d'impression, PDF avec du vrai texte lisible par les logiciels de recrutement.
  - Exportation/Importation en **JSON** pour sauvegarder votre progression.
- 🗣️ **Niveaux de langue CECRL** (A1 → C2) et **équivalence des diplômes** (ex : Bac+2).
- 📏 **Alerte une page** quand le CV dépasse le format A4.
- 🔒 **Données locales** : tout reste dans le navigateur, rien n'est envoyé sur un serveur.
- 📱 **Design Responsive** : Optimisé pour une utilisation sur desktop et tablettes.

## 🛠️ Technologies Utilisées

Ce projet est construit avec des technologies web modernes sans dépendances lourdes pour une performance maximale :

- **HTML5 & CSS3** : Structure sémantique et design système basé sur des variables CSS.
- **Vanilla JavaScript** : Logique métier fluide et gestion d'état sans framework.
- **Google Fonts** : Typographies premium (Inter, Outfit, Playfair Display).
- **html2pdf.js** : Conversion précise du DOM en document PDF.

## 🚀 Installation & Utilisation

1. **Cloner le projet**

   ```bash
   git clone https://github.com/votre-repo/creation-de-cv.git
   ```

2. **Lancer l'application**
   Ouvrez simplement le fichier `index.html` dans votre navigateur préféré. Aucun serveur local ou build n'est requis.

## 💡 Comment ça marche ?

1. Remplissez vos informations dans le panneau de gauche.
2. Personnalisez l'apparence en changeant de template ou de couleur.
3. Observez le résultat en direct à droite.
4. Cliquez sur "Télécharger PDF" pour un téléchargement direct, ou sur "Imprimer le PDF" (puis « Enregistrer au format PDF ») pour un PDF texte.
